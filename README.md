# PicDeliver | GitHub 图像 CDN 极速转换器 🚀

> 基于 GitHub 仓库的极速图片托管、CDN 多节点加速路由与格式转换工具。

---

## 🌟 核心功能

### 1. ⚡ 多线路 CDN 极速加速
- **主流 CDN 节点即时转换**：内置 jsDelivr 镜像源（多线路）、Gcore 专属节点、Cloudflare 等高可用边缘 CDN。
- **自定义节点拓展**：支持自定义配置任意基于 GitHub 的 CDN 路由前缀。
- **无缝实时切换**：一键点击切换 CDN 节点，页面内所有链接、实时预览与复制格式秒级同步响应。

### 2. 📤 图片上传至 GitHub
- **多种便捷上传方式**：
  - 点击选取本地文件
  - 拖拽图片至上传区域
  - **剪切板一键粘贴 (`Ctrl + V` / `Cmd + V`)**：无论在主界面还是上传弹窗中，只要剪切板有图片（如截图），按下快捷键即可直接载入。
- **目录自由配置**：
  - 自动读取仓库现有文件夹列表，支持下拉快捷选择。
  - 支持直接输入创建新文件夹（针对移动端界面已做自适应排版，杜绝长输入框溢出）。
- **智能命名规则**：
  - **时间戳命名**：默认按照「年月日时分秒 (`YYYYMMDDHHmmss.ext`)」规范命名，确保文件名全球唯一。
  - **保留原名切换**：提供复选框，可随时自由切换为「原文件名」。
- **活力提交记录**：
  - 每次提交 GitHub 时，Commit 描述均会随机带上活泼有趣的 Emoji 图标（如 `✨ 在images目录下创建了20261005214814.png`）。

### 3. 🔍 沉浸式大图查看与外链预览
- **选图/粘贴后本地大图查看**：选图后未上传前，点击左侧小缩略图即可直接呼出全屏高清大图。
- **上传成功后大图查看**：点击成功卡片上的缩略图，纯粹展示大图画面，无任何干扰元素。
- **一键外链预览**：输入框外配备独立外链图标，可在新标签页中直接通过 CDN 加速节点访问图片。
- **极简退出交互**：点击空白背景、右上角关闭按钮或按下 `Esc` 键均可轻松关闭大图。

### 4. 📋 丰富多格式复制
- **多种外链格式**：
  - CDN 原始直链（Direct URL）
  - Markdown 语法（`![filename](url)`）
  - HTML 标签（`<img src="url" alt="filename" />`）
  - 论坛 BBCode（`[img]url[/img]`）
- **复制体验**：上传成功后的复制按钮独立外置于输入框右侧；图片列表支持单张复制与批量整页一键复制。

### 5. 📱 优秀的多端与交互体验
- **移动端全适配**：针对手机及平板端布局进行深度打磨，新建目录、弹窗各组件均自动换行自适应。
- **主题与双语**：支持清新浅色与极客深色模式切换，内置全量中英文界面国际化。
- **数据隐私与安全**：Personal Access Token（PAT）仅加密存储在您的浏览器本地 `localStorage` 中，所有网络请求均直连 GitHub 官方 API，绝不上报或中转第三方服务器。

## 🚀 快速使用指南

### 第一步：准备 GitHub 仓库与 Token
1. 创建或选择一个 GitHub 仓库（公开或私有均可）。
2. 在 GitHub 中申请一个包含 `repo` 权限的 **Personal Access Token (PAT)**。
3. 在网站中填入仓库地址（如 `owner/repo` 或完整链接）与 Token，系统将自动记住配置。

### 第二步：上传图片
1. 点击右上角或操作卡片中的 **「上传图片」** 按钮（或直接在页面任意处按下 `Ctrl+V` 粘贴截图）。
2. 选择目标分支与存放目录（已有目录或新建目录）。
3. 勾选是否按年月日时分秒命名。
4. 点击 **「上传图片并获取 CDN 链接」**。

### 第三步：获取并使用加速链接
1. 上传成功后，外置复制按钮可一键拷贝 CDN 直链。
2. 亦可复制 Markdown、HTML 或 BBCode 格式，直接粘贴到博客、笔记（Obsidian / Notion）或论坛中使用。
3. 点击图片缩略图可查看大图；点击链接旁边的外链图标可在新标签页验证 CDN 访问效果。
